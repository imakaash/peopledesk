---
name: leave_request
description: Handling questions about taking time off and leave requests
triggers: [leave, vacation, holiday, time off, day off, days off, pto, sick, parental]
---

1. Work out which kind of leave it is: annual, sick, parental, unpaid or compassionate. If it isn't clear, ask.
2. For a request, collect the start date, end date and leave type. Count working days, not calendar days.
3. Check the notice rule: leave longer than 3 working days must be requested at least 2 weeks ahead. If the dates break this rule, say so before going further.
4. If a leave-balance tool is available, check the balance before submitting, and tell the user what will remain afterwards. Otherwise explain how to request leave in PeopleDesk.
5. Remind the user that their manager approves or declines within 3 working days.
6. For sick leave longer than 3 days, mention that a doctor's note is needed. Don't ask about medical details.
